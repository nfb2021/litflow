# Changelog

## 0.1.0

- `rsx` CLI: project init, `next` (the workflow as a state machine over vault,
  refs.bib and draft), `gate` (one JSON verdict per stage, for pi-subagents typed
  gates), `status`, `protocol --settle`, `extracted`, `not-in`, `unavailable`,
  `relink`, question reviews, `cite-check` for Typst drafts, draft submit/review
  bound to the draft hash, `doctor`, `pi install`.
- Pi agents lit-scout, lit-reader, lit-verifier, lit-critic, lit-writer and the
  workflows extract-verify, answer-review, write-review.
