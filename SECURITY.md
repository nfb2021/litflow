# Security

Please report vulnerabilities privately through
[GitHub security advisories](https://github.com/nfb2021/skills/security/advisories/new),
not in public issues.

Skills here may drive a browser with your own logins (e.g. `gemini_notebook`). Their
login data lives outside the repository and is never committed; secret scanning
(GitGuardian, `detect-private-key`) runs on every push.
